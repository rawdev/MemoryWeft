MWeft — 포터블 설치 (서명 없음 · 압축 풀고 실행)
====================================================

이 폴더는 MWeft Manager 를 "압축 풀기 → 런처 1번"으로 실행하는 포터블
배포입니다. 시스템에 Python 을 설치하지 않으며, 모든 것이 이 폴더 안에서
자기완결로 돌아갑니다. (지우려면 이 폴더만 삭제하면 끝.)

--------------------------------------------------------------------
Windows
--------------------------------------------------------------------
1) (권장) 받은 zip 을 우클릭 → "속성" → 아래 "차단 해제" 체크 → 확인.
   그 다음 압축을 풉니다.  (이러면 보안 표식이 제거됩니다.)
   ※ 7-Zip 으로 풀면 이 단계는 불필요합니다.
2) 폴더 안의  start-mweft.bat  을 더블클릭.
3) 최초 1회만 자동 설정(1~5분) 후 Manager 앱 창이 열립니다.
   "Windows의 PC 보호" 가 뜨면 → "추가 정보" → "실행" (미서명 안내).
   ※ 네이티브 창에는 WebView2 런타임이 필요합니다(Windows 11 기본 내장,
     Windows 10 은 https://developer.microsoft.com/microsoft-edge/webview2/
     에서 설치).

--------------------------------------------------------------------
macOS
--------------------------------------------------------------------
1) zip 을 더블클릭해 풉니다.
2) 폴더 안의  start-mweft.command  를  우클릭 → "열기"  →  "열기" 확인.
   (최초 1회만. 미서명 앱 Gatekeeper 승인 — 이후엔 더블클릭해도 됩니다.)
3) 터미널 창이 뜨고 최초 1회 설정 후 Manager 앱 창이 열립니다.

--------------------------------------------------------------------
종료 / 재시작
--------------------------------------------------------------------
- 종료: Manager 앱 창을 닫으면 됩니다(같이 뜬 콘솔/터미널도 함께 닫힘).
- 재시작: 런처를 다시 실행하면 설정을 건너뛰고 즉시 켜집니다.

--------------------------------------------------------------------
AI 클라이언트 연결 (MCP)
--------------------------------------------------------------------
Manager 앱은 제어판일 뿐입니다. AI 클라이언트(Claude Code/Desktop, Cursor,
Gemini CLI 등)가 이 메모리를 쓰게 하려면 Manager 설정에서 MCP 서버를
등록하세요. 이 폴더의 동봉 런타임 + ONNX 모델을 가리키도록 클라이언트
설정을 대신 작성해 주며, K2G_MCP_LAZY_INIT=true 를 설정해 최초 연결 시
타임아웃을 방지합니다(무거운 초기화는 첫 도구 호출로 미룸).

--------------------------------------------------------------------
데이터 위치 / 업데이트
--------------------------------------------------------------------
- 모든 메모리·설정은  data/  폴더에 저장됩니다 (SQLite). 폴더째 백업/이동 가능.
- 업데이트: 새 버전 폴더로 교체하되, 기존  data/  를 새 폴더로 복사해 넣으면
  메모리가 보존됩니다. (VERSION 이 다르면 런타임은 자동 재설정, data 는 보존)

--------------------------------------------------------------------
문제 해결
--------------------------------------------------------------------
- 설정 실패 / 이상 동작:  runtime/  폴더를 통째로 삭제 후 런처 재실행
  (data/ 는 건드리지 마세요 — 메모리 보존).
- Windows: 앱 창이 안 뜨면 WebView2 런타임을 설치(위 Windows 단계 참고)한 뒤
  런처를 다시 실행하세요.
